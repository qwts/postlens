Advice suggests Skip, Like, Like + follow, Consider mute, or Review. You make the decision using X's own controls; PostLens does not click like, follow, or mute for you. One post cannot establish an account's overall quality, and no action guarantees a ranking change.

Get keys from the TypeSafe dashboard and OpenAI API dashboard. Saved keys are never displayed here. OpenAI API billing is separate from a ChatGPT subscription.

On each analysis, visible post text and available author/metadata are sent to TypeSafe. Images, videos, linked pages, and profile pages are not fetched.

chrome.storage.local is not a secure credential vault. This storage is acceptable for a personal prototype; do not distribute a shared API key with this extension.

Analysis results and generated context are kept locally (up to 500 entries). Changing your goal uses a separate advice cache. After updating settings, refresh X to remove old suggestions. Clearing results means a future Analyze click can incur another API call. Stop any running analyses before clearing.

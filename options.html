PostLens

Analyze individual X posts with Jev when you click JEV Analyze.

Checking saved key…

Get your key from the TypeSafe dashboard. The saved key is never displayed here.

On each analysis, visible post text and available author/metadata are sent to TypeSafe. Images, videos, linked pages, and profile pages are not fetched.

chrome.storage.local is not a secure credential vault. This storage is acceptable for a personal prototype; do not distribute a shared API key with this extension.

Analysis results are kept locally (up to 500 posts). Clearing them means a future Analyze click can incur another API call. Stop any running analyses before clearing.
